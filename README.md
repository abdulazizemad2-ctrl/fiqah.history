# بنك أسئلة المدخل إلى الفقه الإسلامي (تاريخ الفقه)

بنك أسئلة تفاعلي لنطاق اختبار منتصف الفصل (MED)، من مبادئ الفقه إلى مصادر التشريع في عصر الأئمة المجتهدين.

- أسئلة التجميعات وأسئلة جديدة
- اختيارات ومقالي، مقسمة حسب الفصول
- وضع تدريب بتصحيح فوري، ووضع اختبار محاكي (15 اختياري + 3 مقالي)
